# Язык аналитики DRIP

**Аналитическая сессия**: сохраненный анализ одной неизменяемой выборки. Сессии доступны сотрудникам совместно.
_Avoid_: браузерная сессия, изменяемый черновик

**Текущий срез ЕИСЖС**: опубликованное состояние объектов на дату наблюдения.
_Avoid_: список продаж за месяц

**Накопительное количество ДДУ**: опубликованное количество зарегистрированных ДДУ на дату среза. Это не поток новых продаж за период.
_Avoid_: месячные продажи

**Недоступный показатель**: значение не получено или не опубликовано. Его отсутствие не означает ноль. Известный ноль является наблюдением, отсутствие значения им не является.
_Avoid_: нулевые продажи, автоматически рассчитанный ноль

**Отсутствующий результат анализа**: у сессии еще нет сохраненного среза. Значения и подпись источника не придумываются.
_Avoid_: пустой рынок, результат с нулевыми показателями

**Скрытая сессия**: сессия убрана из рабочего места с сохранением ее данных. Операции рабочего места не раскрывают ее как доступную.
_Avoid_: физически удаленная строка, статус deleted
