# Проверка восстановления

Первый restore останавливался на уже существующем ID. Сохранён его исходный log. После исправления fixed.log показывает пропуск первого ID и импорт двух отсутствующих серий. repeat.log подтверждает повторный запуск: все три ID пропущены, exit 0, вызовов модели нет. --force и --new-id не используются, существующие оценки не заменяются.
