# Задания для групп

## 1. Куда положить факт?

Распределите сведения между task prompt, AGENTS.md, REPO_MAP.md, CONTEXT.md, ADR и результатом инструмента:

- Название новой JSON-свойства HTTP-ответа.
- Go и TypeScript создаются из одного OpenAPI.
- API и UI упакованы в один runtime-контейнер.
- Команда узкой проверки HTTP-пакета.
- Накопительное количество ДДУ не равно продажам месяца.
- Фильтры сохранённой аналитической сессии неизменяемы.
- Ошибка последнего теста и его фактический stdout.
- Причина выбора существующего read-only интерфейса диагностики.

Сформулируйте правило, по которому вы сделали выбор. Какие сведения повторяются в каждом запуске, а какие нужны только для этой задачи?

## 2. Написать AGENTS.md

Бюджет - до 20 содержательных строк. Укажите реальные команды и источник контракта. Разделите правила маленькой итерации и release. Проверьте, что каждая строка помогает выбрать действие или ограничивает конкретную ошибку.

До запуска запишите прогноз: что изменится в результате, в траектории и в расходе? После запуска назовите наблюдение, которое опровергает ваш прогноз.

## 3. Сделать карту поиска

Представьте три пользовательских намерения: изменить HTTP-ответ, интерпретировать показатель, получить диагностическую статистику БД. Для каждого укажите один начальный файл и два следующих источника. Объясните связи между ними.

Удалите из карты пути, не помогающие ни одному намерению. Проверьте ссылки командой `python3 seminar/check_context.py`.

## 4. Доменный словарь

На synthetic fixture объясните: что можно сложить, что можно вычесть, какой результат недоступен и где нельзя подставить ноль. Напишите определения 4-6 терминов без команд, имён таблиц и путей к коду.

Сравните словарь с API и UI. Если они расходятся, зафиксируйте конфликт вместо молчаливого выбора удобного значения.

## 5. Историческое решение

Напишите один короткий ADR: контекст, решение, причина и важное последствие. Укажите статус и источник. Отличите фиксацию существующего решения от предложения нового.

Проверьте, помогает ли ADR другой задаче и не содержит ли он готового патча. Что изменится, если решение станет устаревшим?

## 6. Достаточно ли хорош контекст?

Проверьте результат независимым способом. Не используйте финальную реплику агента как единственное доказательство. Обсудите ситуацию, когда проверок стало больше, качество не изменилось, а токены выросли.

На выходе у группы должны быть: краткий AGENTS.md, маршруты карты, словарь, ADR и один измеримый критерий их полезности.
