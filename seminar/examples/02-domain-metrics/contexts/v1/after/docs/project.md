# Описание репозитория

DRIP Недвижимость - учебная копия внутреннего рабочего места аналитика. React UI, contract-first OpenAPI и Go API собираются в один runtime-контейнер. PostgreSQL хранит сессии и записи источников; локальный стенд использует имитатор внешнего API и S3Mock.

Это monorepo. Backend находится в `backend`, frontend в `frontend`, публичный контракт в `api`. Существующий интерфейс и бизнес-поведение сохраняются при небольших изменениях.

Источник этого описания: код базового коммита `d037c2c`, README и Dockerfile. Описание подготовлено для учебного семинара, а не перенесено из истории исходной команды.
