# Коррекция источника для следующего примера

В v1 архитектурная заметка ошибочно назвала deleted статусом. В миграции 001_access.sql удаление хранится в deleted_at, а canceled является допустимым статусом. Пример 2 проверял ДДУ и прошёл независимо от этого неверного утверждения. Его исходные snapshots и отчёты сохранены без изменений. Этот исправленный snapshot используется только как вход before для примера 3; нового результата Promptfoo для v2 не заявляем.
