# Аналитика недвижимости DRIP

Рабочее место аналитика для сохранённых аналитических выборок по внешним источникам. Термины описывают предметную область; архитектура и команды находятся в отдельных документах.

## Аналитические сессии

**Аналитическая сессия**:
Сохранённый анализ одного запроса и одной неизменяемой аналитической выборки. Сессии общие для сотрудников.
_Avoid_: браузерная сессия, личный черновик, изменяемая выборка

**Активная аналитическая сессия**:
Сессия, которая ожидает получения данных или получает их. Завершённая частично сессия не является активной.
_Avoid_: любая не удалённая сессия, любая незавершённая сессия

**Завершённая аналитическая сессия**:
Сессия, получение данных которой завершилось полностью. Завершённая частично и неуспешная сессии - самостоятельные состояния.
_Avoid_: любая остановленная сессия, завершённая частично

**Удалённая аналитическая сессия**:
Сессия, скрытая из рабочего места без физического удаления её данных. Статистика рабочего места учитывает видимые сессии.
_Avoid_: физически удалённые данные, активная сессия

## Данные источника

**Текущий срез ЕИСЖС**:
Опубликованное состояние объекта на дату наблюдения. Он не является списком сделок за календарный месяц.
_Avoid_: сделки месяца, продажи месяца

**Накопительное количество ДДУ**:
Опубликованное накопительное значение зарегистрированных ДДУ на дату среза. Оно не задаёт поток новых продаж за интервал.
_Avoid_: месячные продажи, количество новых сделок

**Разность накопительных показателей**:
Разность двух доступных сопоставимых значений одного объекта. В ней могут смешиваться новые регистрации, расторжения и корректировки.
_Avoid_: чистые продажи, точное количество новых ДДУ

**Продажи месяца**:
События продаж за календарный месяц. По двум накопительным срезам количество таких событий не определяется.
_Avoid_: разность агрегатов ДДУ, изменение накопительного значения

**Недоступный показатель**:
Показатель, который источник не опубликовал или который не был получен. Отсутствие значения не является наблюдением нуля.
_Avoid_: нулевой показатель, отсутствующие продажи

**Покрытие показателя**:
Состав объектов с доступными сопоставимыми значениями. Сумма по известной части не является полной суммой при неполном покрытии.
_Avoid_: весь рынок, полная сумма по неизвестным объектам
