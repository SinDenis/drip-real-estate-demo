# DRIP Недвижимость

Демонстрационная платформа аналитики рынка недвижимости: React, Go, PostgreSQL и OpenAPI.

## Запуск

```sh
make dev-up
```

Приложение: <http://localhost:8088>.

На новой базе создаётся локальная учётная запись `admin` с временным паролем `Bootstrap-Admin-2026!`. После входа необходимо задать постоянный пароль. При существующем томе PostgreSQL сохраняются данные и учётные записи этой базы.

Локальный стенд использует имитатор внешнего API и тестовое S3-хранилище. Данные PostgreSQL находятся в отдельном Docker-томе и сохраняются между запусками. `make dev-down` останавливает стенд без удаления этого тома.

## Проверка

```sh
make verify-fast
make e2e
```

Все доступные команды: `make help`. Для локального запуска проверок нужны Go из `backend/go.mod`, Node.js 24.20.0, Docker Compose, Git и jq.
